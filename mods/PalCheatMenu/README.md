# PalCheatMenu MAX

Menu de triches ultime pour **Palworld 1.0 (Steam)** utilisant **UE4SS (RE-UE4SS)**.

## Fonctionnalités

- **Joueur** : God Mode, endurance infinie, faim/soif infinies, pas de degats de chute, vol, no clip, invisibilite, super vitesse (slider x1-x20), super saut (slider 500-20 000).
- **Combat** : munitions infinies, pas de rechargement, One-Hit Kill.
- **Inventaire / Craft** : objets infinis, craft instantane, ignorer couts, dupliquer items.
- **Pals** : Pal God Mode, Pal Sanity infinie, eclosion instantanee, stats max.
- **Monde / Progression** : +XP (jusqu'a 10 M), +points tech (jusqu'a 1000), regler l'heure, freeze time, unlock fast travel, teleportation devant, meteo claire.
- **Interface** : menu ImGui a onglets, sliders, boutons "Tout activer / Tout desactiver".

## Installation

1. Installez **RE-UE4SS** dans `Pal/Binaries/Win64`.
2. Copiez le dossier `PalCheatMenu` dans `Pal/Binaries/Win64/Mods/`.
3. Lancez Palworld.
4. Appuyez sur **F1** pour ouvrir/fermer le menu.
